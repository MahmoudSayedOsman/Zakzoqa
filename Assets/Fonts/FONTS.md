The OFL allows use in a commercial game. Its one duty when the font ships inside the game: the
copyright and licence notice must go with it. The credits or licences screen must list it before
release (Docs/Decisions.md).

`NotoNaskhArabic SDF.asset` is the dynamic font asset UI Toolkit's Advanced Text Generator draws
with (created by Zakzoqa > Set Up UI).
